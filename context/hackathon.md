# AI Research Hackathon — working notes

Source: [Iterate AI Research Hackathon](https://iterate.inc/ai-research?welcome=true&tab=resources) and the event information provided in the team's pasted notes.

## Event

- **When:** November 14–15, 2026
- **Where:** Wefunder, 1885 Mission St, San Francisco
- **Team size:** 3–5; team members must be physically present
- **Build window:** Work must be built during the event; no prior repository commits
- **Submission deadline:** Sunday, November 15 at 2:00 PM PT (hacking ends; submissions due)
- **Required deliverables:** selected track and challenges, public GitHub repository, 2-minute demo video, and short project description
- **Judging:** research rigor, novelty, results, autonomy/self-improvement, and interpretability/reproducibility (20% each)

## Tracks

1. **Build Your Own Autoresearch Framework:** Run an autonomous research loop against a known mathematics result, with decisions and logs that can be followed.
2. **Recursive Self-Improvement by Pacific — AI Scientist for GPU Value:** Forecast H100/A100 resale or cloud rental prices. Submit starter-kit-format forecasts, a reproducible command, and concise findings. Forecasts are scored at 1-, 3-, and 7-day horizons against post-November 6 rental prices.
3. **AI Scientist Swarms:** Use role-differentiated agents to reproduce computational biology studies from raw data, with cross-checking and reporting of rejected findings. BixBench3 is the cited benchmark; its best score is 0.523.
4. **World Models:** Improve how long an open generated world stays coherent while an agent plays; evaluate against PlayWorld scores.
5. **Open Track:** Projects that do not fit tracks 1–4.

## Sponsor challenges (optional)

- **Exa research agents:** At least one Exa API call must run in the main loop. Show what the agent found from Exa and how it used the sources.
- **past.dev multi-agent memory:** More than one agent must write and read shared memory, and an agent must use something another agent wrote. Explain memory roles in the README.
- **Modal:** Award for the strongest use of Modal for training, inference, or parallel experiments and agent sandboxes.
- **Originator:** Participate through hackwithori.com or upload sessions; the event notes list cash prizes for the top three.
